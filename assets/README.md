# Assets (Godot)

Estructura para ir añadiendo contenido:

- **mobs/** — Enemigos (sprites, spritesheets). Ej.: `Bringer-of-Death-SpritSheet.png`
- **level-up/** — Orbes y objetos de subida de nivel (red = vida, green = power, blue = energía)
- **map/** — Fondos y tiles de mapa (grass, zonas)
- **player/** — Sprites del jugador (variantes, animaciones)
- **fonts/** — Fuentes (PixelOperator, etc.)
- **sounds/** — Sonidos y música
- **weapons/** — Sprites de armas/proyectiles
- **craftpix/** — Assets del pack Craftpix (vampire_4dir, etc.)

En las escenas se usa `res://assets/mobs/`, `res://assets/level-up/`, etc.
